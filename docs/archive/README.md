# Archive

Historical planning and status documents from ShiftIQ's development. These
describe design decisions and progress at various points in the project's
history — some predate the "ShiftIQ" name settling in (the app was
prototyped under the working title "Financial Reality Engine" / "FRE"; all
in-repo references to that name have been updated here to ShiftIQ for
clarity).

These files are kept for reference only. They are **not** current
documentation — for that, see the root `README.md`, the `docs/` folder, and
`CHANGELOG.md`.

| File | What it is |
|---|---|
| `build-report.md` | End-to-end build report written after the initial system was complete |
| `engineering-review.md` | A senior-engineer-style review of the codebase's architecture |
| `finishing-plan.md` | A punch list used to take the project from prototype to polished |
| `mlp-product-strategy.md` | Product strategy notes on scoping a "minimum lovable product" |
| `progress-report.docx` | A point-in-time status report |
